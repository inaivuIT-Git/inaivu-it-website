# inaivu IT website

Official source for [inaivuit.com](https://inaivuit.com).

## Structure

- `dist/` — production-ready static website
- `.github/workflows/pages.yml` — GitHub Pages deployment

## Local preview

Open `dist/index.html` directly, or run a local static server from `dist/`.

## Contribution workflow

1. Create a branch from `main`.
2. Make and test the change.
3. Open a pull request.
4. Merge after review; GitHub Pages deploys automatically.

Do not commit passwords, API keys, hosting credentials or customer data.
